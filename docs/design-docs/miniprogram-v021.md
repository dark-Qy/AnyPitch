# 微信小程序视觉与功能边界

## 当前产品范围

网页管理员发布活动、赛事专题、相册照片和战术板；微信小程序面向队员查看与分享活动、提交固定状态报名、查看训练榜和个人记录，并可分享入队邀请及上传自己的头像。底部入口为活动、报名、训练榜、我的；赛事专题是只读页面。小程序相册、成员发布野球及原生教练编辑页面已移除。现有相册和头像数据不删除；网页成员相册只读。

服务端按会话类型执行边界：微信成员会话不能创建活动、建立相册、上传照片或编辑删除照片；头像仅能为本人上传，经服务端图片校验和微信异步审核后可见。管理员密码会话仍可使用网页管理功能。昵称保留作为成员基本身份信息，文字审核继续执行。报名依旧只有参加、不参加、待定、未确认，取消与过期活动不能报名。

## 视觉实现

白色表面、深蓝正文与主操作；训练蓝、友谊赛橙、野球青绿。分类映射集中在 `miniprogram/utils/design.js`，类型标签共用 `components/type-badge`。页面、活动与章节标题使用思源宋体 Medium；正文、按钮和表单为系统无衬线，字重 400／500／600。原队徽直接复用，XTC FC 字标为窄体斜体 SVG 路径。

活动列表共用当前／历史布局，保留类型、地点筛选与真实报名数据。月历默认收起，从活动列表标题处按需展开；展开后原列表仍在下方。月历按北京时间标出当前筛选范围内有活动的日期，点选日期定位到列表中的对应活动，不清空其他活动；当天无匹配活动时给出提示。插画为训练锥＋足球、双方球衣、弹跳足球；不携带日期或口号。最多三个成员头像叠放，额外人数来自 API，无头像显示昵称首字。点成员头像可查看队内只读资料、头像大图和训练／友谊赛参加报名次数；统计沿用训练榜口径。报名页对近期活动逐场提供四种固定状态。功能图标使用统一 Lucide 线宽，核心触控区至少 44px。

## 字体与验证

思源宋体 WOFF 子集包含 GB2312 常用简体中文、界面文案、数字和标点，附 OFL 许可证；修改后的内部名为 AnyPitch Serif。构建脚本为 `scripts/build_miniprogram_fonts.py`，文件位于 Web 静态发布目录，页面就绪后通过自有 HTTPS 全局加载。

0.2.18 功能收缩版已上传开发版、生产服务端已切换；尚未重新送审或公开发布。开发者工具与真机验证需分别记录。审核是否接受该产品范围仍以微信后台实际结果为准。
