# System Boundaries

AnyPitch 是单支球队的训练组织网页。Go 服务和 SQLite 拥有业务真相，React 只展示并调用明确 API。

## 服务端

服务启动时创建 schema。教练 Bearer session 可管理所属 team；队员 session 只可通过 `/api/player/*` 查看活动、报名、历史、榜单、专题及既有相册。活动发布和相册写入只允许网页管理员 session；队员 session 的写入限定为昵称与固定报名状态。

日常活动和校长杯分开存储：活动支持 `training`、`friendly`、`pickup` 和取消记录；专题用自己的届次和条目表示。报名只保存四状态，训练与友谊赛「参加」报名直接计入榜单。训练榜由服务端实时计算，前端不派生统计口径。

相册元数据在 SQLite，文件在独立上传目录。图片读取始终经 API 授权，不作为公开 `web/dist` 资源。

## 前端

电脑端用窄侧栏组织教练工作台；手机端用可横向到达的主导航。活动首页先呈现下一场和报名；详情再提供编辑、取消、报名和相册。战术板保留操作能力而不是静态预览。

## Out Of Scope

- 多球队、赛事系统、通知、PWA 和原生应用。
- 视频与 HEIC 转码。
- 旧九状态出勤数据的自动推断或自动迁移。
