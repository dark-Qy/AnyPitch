# Coach Workbench

## Goal

让教练在一个响应式 Web 工作台里完成队员管理、日程安排、出勤登记和战术板部署。

## Main Flow

1. 教练使用默认账号登录
2. 添加队员及位置
3. 维护常用地点，默认使用北京邮电大学（海淀校区）
4. 创建训练或友谊赛日程，填写开始/结束时间段和地点
5. 点击月历中的具体日程，在日程详情内登记队员出勤
6. 选择 5/8/11 赛制，再选择该赛制下的我方模板
7. 可选开启对手站位，选择同赛制对手模板，拖拽双方站位并保存

## Acceptance

- API 支持计划中的公共接口
- Web 在桌面和手机宽度下可用
- 日程支持时间段、地点下拉管理，以及在日程详情内维护队员出勤
- Smoke 脚本覆盖完整主路径
- 战术板保存结果包含稳定模板 ID，以及我方/对手 slots 的 `side`
