# Coach Workbench

## Goal

让教练把下一场活动、报名和战术放在同一套响应式网页中；让队员在手机上用很少步骤确认参与。

## Main Flow

1. 教练或队员选择入口登录。
2. 教练维护队员、常用地点和训练/友谊赛/野球活动。
3. 每位队员的报名以参加、不参加、待定、未确认之一独立自动保存。
4. 成员自由注册，在小程序浏览活动并提交自己的固定状态报名；教练在网页端发布和管理活动，负责人指定教练账号。
5. 月度、年度、半年度和学期榜只统计微信成员的训练与友谊赛参加报名。
6. 教练维护校长杯专题及其安排、赛果和相册；它不和训练出勤绑定。
7. 网页管理员向活动或专题相册上传照片；队员在网页端只读查看。
8. 教练选择 5/8/11 人制模板，按需加入对手站位，拖拽并保存战术板。

## Acceptance

- 训练与友谊赛参加报名直接计入训练榜，取消活动不计。
- 野球是日常活动类型，校长杯是独立专题，不会污染训练统计。
- 有历史记录的队员只能停用，活动有记录后用取消代替删除。
- 队员只查看自己的逐场状态和历史，教练才可看全队历史及 CSV。
- 管理员上传的照片刷新和服务重启后可见，读取经过登录鉴权，发布包不包含上传目录。
- 教练与队员在桌面、768px 平板、390px 和 360px 网页宽度可完成主路径。
