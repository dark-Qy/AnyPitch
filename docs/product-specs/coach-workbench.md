# Coach Workbench

## Goal

让教练在一个响应式 Web 工作台里完成队员管理、日程安排、出勤登记和战术板部署。

## Main Flow

1. 用户选择教练或队员入口
2. 教练使用邮箱和密码登录，密码可由环境变量覆盖
3. 教练添加、编辑、删除和停用队员
4. 维护常用地点，默认使用北京邮电大学（海淀校区）
5. 创建训练或友谊赛日程，填写开始/结束时间段、地点和训练内容等备注
6. 点击月历中的具体日程，在日程详情内登记队员出勤
7. 队员输入自己的姓名进入日程页，只维护自己的参加状态
8. 选择 5/8/11 赛制，再选择该赛制下的我方模板
9. 可选开启对手站位，选择同赛制对手模板，拖拽双方站位并保存

## Acceptance

- API 支持计划中的公共接口
- Web 在桌面和手机宽度下可用
- 日程支持时间段、备注、地点下拉管理，以及在日程详情内维护队员出勤
- 队员入口无需密码，只能查看日程和保存自己的参加状态
- Smoke 脚本覆盖完整主路径
- 战术板保存结果包含稳定模板 ID，以及我方/对手 slots 的 `side`
